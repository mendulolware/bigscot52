# BigScot52 Local Website

## Run it
1. Unzip this folder.
2. Open a terminal in the folder.
3. Run one of these:

### Python
`python -m http.server 8000`

Then open http://localhost:8000

### Node
`npx serve .`

Then open the localhost address it gives you.

The site is plain HTML/CSS/JS, so there is no build step.
Replace `bigscot52-pfp.png` with another square image if you want a different profile picture.
